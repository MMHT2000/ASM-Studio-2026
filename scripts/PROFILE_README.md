### ⚡ **[ASM Studio 2026 — Intel 8086 Assembly IDE & Visual Emulator](https://github.com/MMHT2000/ASM-Studio-2026)**

*A pedagogical, cycle-accurate Intel 8086 microprocessor development suite built to replace legacy 16-bit DOS-box emulators for university students and systems engineers.*

[![Live Web App](https://img.shields.io/badge/Launch%20Web%20App-Zero%20Install-brightgreen?style=for-the-badge&logo=google-chrome&logoColor=white)](https://mmht2000.github.io/ASM-Studio-2026/)
[![Windows Executable](https://img.shields.io/badge/Windows-v1.1.0%20x64-blue?style=for-the-badge&logo=windows&logoColor=white)](https://github.com/MMHT2000/ASM-Studio-2026/releases/download/v1.1.0/ASM-Studio-2026-v1.1.0-Windows-x64.zip)
[![Ubuntu .deb](https://img.shields.io/badge/Ubuntu%20%2F%20Debian-.deb%20Package-E95420?style=for-the-badge&logo=ubuntu&logoColor=white)](https://github.com/MMHT2000/ASM-Studio-2026/releases/download/v1.1.0/asm-studio-2026_1.1.0_amd64.deb)
[![Linux Tarball](https://img.shields.io/badge/Universal%20Linux-.tar.gz%20Portable-FCC624?style=for-the-badge&logo=linux&logoColor=black)](https://github.com/MMHT2000/ASM-Studio-2026/releases/download/v1.1.0/ASM-Studio-2026-v1.1.0-Linux-x64.tar.gz)

**Highlights**: 16-Bit Real Mode CPU Core • Time-Travel Step Back (<kbd>Shift+F10</kbd>) • Virtual Hardware Bus (Traffic Lights, 7-Segment, 8-Bit LEDs) • Multi-Provider AI Tutor (Gemini, GPT-5/o3, Claude) • Monaco Editor
